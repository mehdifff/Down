# دانلودر هوشمند 🎬

یه سرور کوچیک که لینک صفحه فیلم رو میگیره، لینک مستقیم دانلود رو پیدا میکنه و به ADM میفرسته.

---

## نصب و راه‌اندازی

### مرحله ۱ — نصب Python
به سایت https://python.org برو و Python 3.10 یا بالاتر رو نصب کن.
موقع نصب تیک **"Add Python to PATH"** رو بزن.

---

### مرحله ۲ — اجرای سرور

#### ویندوز:
فایل `start.bat` رو دابل‌کلیک کن.

#### مک/لینوکس:
ترمینال رو باز کن، بنویس:
```
cd downloader
./start.sh
```

---

### مرحله ۳ — باز کردن اپ روی گوشی
بعد از اینکه سرور روشن شد، از گوشیت (که به همون WiFi وصله) این آدرس رو باز کن:

```
http://[IP کامپیوترت]:5000
```

برای پیدا کردن IP کامپیوتر:
- **ویندوز:** تو CMD بنویس `ipconfig` → دنبال IPv4 بگرد
- **مک:** تو Terminal بنویس `ifconfig | grep inet`

---

## استفاده

1. لینک صفحه فیلم یا سریال رو وارد کن
2. اگه میخوای زمان‌بندی کن (مثلاً ساعت ۳ صبح)
3. بزن «افزودن به صف»
4. سرور لینک مستقیم رو پیدا میکنه
5. وقتی وضعیت «آماده» شد، «ارسال به ADM» رو بزن

**نکته مهم:** سرور (کامپیوتر) باید روشن باشه تا زمان‌بندی کار کنه.
